# Serene Tiles website

Standalone static website and privacy policy.

## Local preview

Run `python3 -m http.server 8765 --bind 127.0.0.1` from this folder, then open http://localhost:8765/.

GitHub Pages serves the main branch root. The app is pre-release. Included images are design concepts, not App Store screenshots.

Before App Store submission, confirm the public developer/support contact and review final app privacy declarations.
